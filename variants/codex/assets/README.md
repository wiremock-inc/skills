# OpenAI listing images

`logo.png` (512×512) and `composer-icon.png` (256×256) are the official WireMock logo mark, `logo/1_WireMock_Logo.svg` from [wiremock/community](https://github.com/wiremock/community/tree/main/logo) (CC0-1.0). They were rasterised unmodified with `rsvg-convert -w <size> -h <size>`. The build copies them into `codex/assets/`.
