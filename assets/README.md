# Shared listing assets

`wiremock-logo.png` (512×512) is the official WireMock logo mark, `logo/1_WireMock_Logo.svg` from [wiremock/community](https://github.com/wiremock/community/tree/main/logo) (CC0-1.0). It was rasterised unmodified with `rsvg-convert -w 512 -h 512`. The build copies it into each plugin that shows a listing logo: `codex/assets/logo.png` and `cursor*/assets/logo.png`.

The OpenAI composer icon (`variants/codex/assets/composer-icon.png`, 256×256) is the same mark at a smaller size.
